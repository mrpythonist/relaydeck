Pricing

RelayDeck receives webhooks from Stripe, GitHub, Shopify and your own systems, stores each event durably first, then delivers it with retries. Delivery is at-least-once. No exactly-once or zero-loss guarantee is claimed.

Free - $0 / month

  • 1,000 events per month
  • 3 destinations
  • 3 days retention

Starter - $19 / month

  • 50,000 events per month
  • Unlimited destinations
  • 30 days retention

Growth - $49 / month

  • 500,000 events per month
  • Unlimited destinations
  • 90 days retention

Over the monthly limit, ingestion returns HTTP 429 until the next calendar month. Retries do not count against the limit. Create an account to get a workspace and an ingest URL.

How it works

  1. Create an account and a workspace.
  2. Add a destination, for example your API endpoint.
  3. Point Stripe or GitHub at POST /ingest/{workspace_public_id}/{source}.
  4. Watch deliveries, retries and failures in the dashboard. Replay any event.

Prefer to run it yourself? RelayDeck is open source and self-hostable with one binary and one SQLite file. See the README.
